# AC-Hacking
D-Lab WASH: AC Hacking Team Files and Images

**Abstract:**
This project is being completed in coordination with Cynthia Acquaye and her team of mentors at Delft University of Technology in the Netherlands. The project’s goal is to explore the potential of using AC units to create clean drinking water. Through mapping the feasibility of this solution in Accra and investigating the production of condensate in a window AC unit, this project hopes to demonstrate the potential of this solution. The project maps factors such as temperature, humidity, and precipitation, as well as investigates electricity usage and maps water access to determine the areas best suited to deploy the project. This project also provides insights into modifying AC units to strike a balance between cooling capacity and drinking water production.
